# 反复提问登记表（PAINPOINTS）

跨会话记录「用户反复提问 / 明确说记不住 / 反复出错」的知识点。**写任何笔记大纲前先查本表**；已登记的知识点直接满足可视化决策流程（SKILL.md）第 1 步的门槛第 4 条——即必须配组件，并在大纲提案中写明升级动作。

## 登记规则

1. 同一知识点在对话中被**再次问到**，或用户明说「之前问过」「老是记不住」→ 当场登记一行
2. 已有笔记的知识点：在下次修改/学习相关内容时，大纲提案中提出该笔记的**可视化升级建议**（加组件 / 换更合适的组件 / 加深追问链）
3. 尚无笔记的知识点：提高该主题的写作优先级，写笔记时该知识点**必须**配组件
4. 升级动作完成后，把该行移到下方「已消化」区存档，不删除
